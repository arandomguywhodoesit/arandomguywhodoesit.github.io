# Cybersecurity & IT Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript, intended for deployment with GitHub Pages.

## What's included

- Responsive homepage and navigation
- About and professional approach sections
- Cybersecurity lab cards
- IT and Python project showcase
- Technical knowledge base links
- Starter Markdown write-ups
- Basic accessibility and reduced-motion support

## Before publishing

1. Replace `YourName` / `Your Name` with your preferred display name.
2. Replace every `https://github.com/` link with your GitHub profile or repository URL.
3. Replace `your.email@example.com` with your professional email, or remove the email button.
4. Verify every lab status. Do not present planned labs as completed work.
5. Add your own screenshots and sanitized evidence.
6. Remove anything that reveals credentials, private IPs/hostnames, employer information, or other sensitive data.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload the files and folders from this project to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment and open `https://YOUR-USERNAME.github.io`.

If you use a repository with a different name, the site URL will normally be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Add a new project

1. Create a Markdown file under `labs/`, `notes/`, or `projects/`.
2. Document the objective, environment, method, evidence, analysis, findings, limitations, and lessons learned.
3. Add a link to the project from `index.html`.
4. Commit and push your changes.

## Safety and honesty

Only test systems you own or have explicit permission to assess. Use a controlled lab for security testing and malware analysis. Clearly distinguish simulations from real incidents, and describe limitations rather than claiming certainty unsupported by evidence.
